# 📌 Overview

The **Sign Language Translator** is an AI-powered web application that detects and translates sign language gestures into text and speech in real time.

This project combines:
- 🧠 Deep Learning
- 📷 Computer Vision
- 🌐 Flask Web Framework
- 🔊 Text-to-Speech Technology

The main goal of this project is to improve communication accessibility for people with hearing or speech impairments.

---

# ✨ Features

✅ Real-time sign language detection  
✅ CNN-based gesture classification  
✅ Interactive Flask web application  
✅ Text-to-speech output  
✅ Clean and responsive UI  
✅ Model evaluation support  
✅ Easy to train and deploy
